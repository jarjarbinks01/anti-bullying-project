# 獨立家長分析

此分析讓沒有可用學生問卷的家長回應仍可建立基線及跨期樣本。它使用同一份發布資料及已確認孩子身份，另行計算家長的測量輪次。學生錨定的 A–D、AC、BD、E、F、EF 不改。

## 研究規則

孩子身份仍使用完整生日、有效性別及聯絡證據：同校加精確聯絡、同校加有效八位電話同一位置恰好差一位，或不同校加精確聯絡。生日、性別及學校相同本身不足以合併。班號及學號不作身份門檻。

獨立分析重用 pipeline 已確認的孩子群組，不自行合併尚未連起的子群。有學生身份證據時可以沿用，但不要求學生有可用 T0／T1。全體家長資料在學生錨定選取之前複製，這個分支不修改原 record、孩子身份、提交ID、來源版本、人工決定、永久親子ID或審核任務。

同一成人須有有效且一致的出生年份，並在任一已接受聯絡欄中有精確電話或電郵交集。多項聯絡逐項拆分；與孩子關係只供參考。已驗證的人工 LINK_ADULT／UNLINK_ADULT 優先，失效證據重新待審；出生年份錯字例外不傳遞到第三份回應。成人候選還須互相符合成人身份規則，不能只靠共通基線串起不同成人。

## 兩個分支如何選取

1. 每個孩子的最早合資格家長回應為共用 T0。孩子資料不完整或有矛盾時，留在處理追查表。
2. 「同一孩子，填卷人可不同」選至少相隔90日的最新合資格家長回應為 T1。
3. 「同一孩子、同一成人」選與共用 T0 填卷人相同、至少相隔90日的最新合資格回應為 T1。此 T1 可以與第一個分支不同。
4. 90日按實際時間間隔，至少90乘24小時。日期可信度沿用 observed、manual_verified、accepted_creation_time；批次指定建立時間保留標記，不能宣稱是實際填卷日期。
5. 一個孩子有日期缺失或不可靠的合資格家長回應時，兩個分支均暫緩選取，因為該份回應可能改變最早基線。最早日期同時刻有競爭回應也暫緩；最新 T1 同時刻有多份時，只暫緩無法唯一選取的分支，不按ID、檔案或行次序猜選。
6. 確認同一成人後，才處理不足30日的重填。基線受到保護；其他重填保留較新一份，整個重填群組仍須符合成人身份證據。另一位家長不會被當作同一成人重填。manual KEEP 保留；所有原回應和 duplicate_of 對應仍可追查。

例如，最早母親回應是基線，之後有合資格母親及更晚父親回應：孩子分支選更晚父親；成人分支選同一母親的最新合資格回應。不能稱未確認的成人為已證實「不同家長」。

## 成人電話差一位試算

此試算要求同一孩子、有效一致成人出生年份，電話為有效八位數且同一位置恰好差一位。沒有精確成人聯絡時才標記為新增近似候選。交換兩位、插入、刪除或近似電郵不納入。

試算仍受人工限制、重新待審及整組成人矛盾檢查約束，只輸出另一套候選及選取結果，**不進入正式同一成人樣本、正式審核派工或原BD**。報告新增孩子群組、共同群組、不同T1及因競爭證據而暫緩的群組。這些是規則比較，不是準確率。既有人工標籤僅在兩份來源版本仍一致時標示，沒有標籤清楚列為未核實。

## 同事如何查看

1. 開啟本機 Dashboard，選「獨立家長分析」。頁首三個數字分別為獨立基線、同一孩子跨期及同一成人跨期。
2. 選孩子或成人分支、獨立 T0／T1。預設「跨期樣本」及「全部學校」，清除其他篩選即可重現頁首的對應跨期數字。
3. 孩子分支可改「全部獨立基線及追蹤」，查看沒有 T1 的基線。它們不會出現在兩份配對表，但會在選定回應下載中。
4. 學校類型、學校、性別及來源按目前輪次的回應篩選。頁面分開列未篩選N、學校範圍後N及目前N；配對表跟隨同一批提交ID。T0／T1來源不同時，分別篩選兩輪可以得到不同N。
5. 描述統計沿用共用計分層，每項顯示樣本N、有效N及缺失N。PHQ描述成人；孩子分支可能換人，不能把其PHQ差異直接解讀成同一成人變化。
6. 「成人電話差一位試算及核實狀態」只供研究者比較。正式配對、選定回應及描述統計分別可下載。

原始輪次、學生錨定輪次及獨立輪次是不同欄位，不能互相覆蓋或將兩種樣本數相加。

## 輸出與每行的意思

所有檔案隨同一個已發布版本保存，Dashboard只讀此版本。

| 檔案 | 一行代表甚麼 |
|---|---|
| independent_parent_analysis.parquet | 一個分支的一輪選定回應；孩子分支包括全部基線，成人分支只包括正式跨期樣本 |
| independent_parent_pairs.parquet | 一個分支的一組T0／T1；包含永久提交ID、版本、日期依據及兩套輪次 |
| independent_parent_audit.parquet | 每一份輸入家長提交的獨立處理結果，包括排除、日期待處理、重填及額外回應 |
| independent_parent_candidates.parquet | 一組基線與後續回應的成人證據判定、試算及同版本核實標記 |
| independent_parent_sensitivity.parquet | 一個孩子群組在精確與近似試算中的選取差異 |
| independent_parent_guard.jsonl.gz | 正式孩子及成人跨期連結的發布防護；已知NONMATCH不得確認發布 |
| independent_parent.xlsx | 六張唯讀工作表，整合數量、正式配對、選定回應、全部追查、成人候選及試算 |

panel_branch 為 child_report 或 same_adult；panel_wave 為獨立輪次；claimed_wave為原問卷標籤；anchored_wave為學生錨定輪次。audit 的 input_status 是獨立分析前資格，status／selected_wave 是學生錨定處理結果；panel_status 是獨立分析結果。不同處理狀態不互相覆寫。

本機Excel是研究輸出，不是人工修正匯入包。需要修正身份、日期或答案時仍使用既有受控流程，批准、套用並重跑後才更新 Dashboard。新分析本身不新增永久親子ID或發出邀請。

## 執行與驗收

沿用現有 Run Pipeline 及完整批次清單，無須額外手動匯入家長分析。先建立未發布版本進行比較，再使用既有發布或回退入口；兩個資料庫及恢復檢查沿用現有備份機制。

驗收必須檢查：相同來源重跑的選定ID一致；原A–D／AC／BD／E／F／EF的數量及提交清單一致；兩個新分支共用基線；每組日期符合90日；Dashboard、摘要、配對表與選定回應的ID逐筆對應；新NONMATCH也能阻止未發布版本被發布。測試另覆蓋單獨家長、換人、共享聯絡、多項聯絡、兄弟姊妹、轉校、近似電話、矛盾連鎖、短期重填、89／90日及日期競爭。

分析的政策版本為 independent_parent_earliest_90d_v1。提交ID保持永久；輪次選取是版本化研究結果，新資料或有效修正可能改變某一版本的選取，不能把分析基線當作另一個永久身份ID。
