# 現行身份、跨期及親子配對規則

本文件只說明程式規則，不包含真實個案、數量或審核答案。

本文的 BD／E／F／EF 使用學生錨定輪次。另行發布的家長獨立基線及跨期分析見 [INDEPENDENT_PARENT_ANALYSIS.md](INDEPENDENT_PARENT_ANALYSIS.md)，其90日門檻不回寫到本文件的學生錨定家長輪次。

## 孩子身份

提交、孩子及成人填卷人分開識別。電話不能單獨代表孩子；家長回應先確認所指孩子。

自動確認要求完整孩子生日、有效性別一致、已映射學校、候選唯一，而且整個群組沒有身份矛盾。已接受三類聯絡規則：同校及精確電話／電郵；同校及有效電話恰好在同一位置差一位數字；不同校但精確聯絡一致。

電話近似兼轉校、互換兩位、位數不同、生日／性別缺失或矛盾，以及無法區分的多候選人，不自行合併。年級（原始值及整理值）、班號／學號與填卷日期間隔均不作孩子身份配對門檻；缺填或不同不因此拒配或把整組轉為待審。這些欄位仍保留供追查，年級及時間異常繼續提示。缺失身高／體重不是身份證據。

逐對相符仍須檢查整組一致性，避免共享聯絡形成矛盾連鎖。提交總數的奇偶不作身份或去重條件。

若兩個孩子在所有可用身份欄位均相同，現有規則無法自行區分；不能宣稱班號缺失已排除雙胞胎。已有人工 UNLINK／NONMATCH 繼續生效，不會因移除班號門檻而自動重連。

## 同一成人與 BD

BD 要求同一孩子及同一成人。2026-10-15確認的自動成人規則為：兩份家長回應指向同一個已確認孩子，成人出生年份有效且一致，所有聯絡欄中至少一項精確電話／電郵相同。與孩子關係及「其他」關係文字保留供查看，缺填或不同不阻擋同一成人確認。

多項聯絡按半形／全形分號、逗號、斜線或換行逐項拆分，電話及電郵分別清理後取集合交集。電話統一香港8位數格式，電郵忽略大小寫；兩份本人聯絡完全不同，仍可按其他聯絡欄的共同項目確認。成人電話差一位或近似電郵不能自動確認。`adult_contact_scope=any_exact`取代舊版「本人缺失才使用其他聯絡」政策；孩子身份的聯絡解析範圍維持原有規則。

成人出生年份缺失、無效或矛盾仍須人工核實。有效人工決定優先，並同時約束家長短期重填及BD；人工「確認不同」不能被較寬鬆的自動規則重連或去重。已接受出生年份錯字而正確年份未知時，保留原值及 `adult_birth_year_status=unconfirmed`。歷史親屬稱呼裁定保留，但新案例毋須因稱呼不同申請例外。出生年份例外只適用於已核實的兩份提交，不能延伸至第三人的矛盾證據。互相矛盾的人工決定須重新裁定。

新的成人證據快照包含所有已解析聯絡。舊快照只在原始提交版本相同、舊解析結果亦可精確重現時沿用；舊人工決定不改寫。整組仍檢查不同候選成人間是否一致，不透過聯絡橋接推定所有人相同。

## 輪次及短期重填

先用上述身份證據分組；30 日不是確認身份的條件。學生 T0 是最早合資格原始回應，短期重填不取代基線。原標 T1 的首次學生回應可推定 T0，保留原標籤及理由。學生 T1 選最新且距學生 T0 至少 90 × 24 小時的合資格回應；學生30–89日保留為未達門檻 follow-up。

2026-10-16 更新為 `parent_wave_policy=student_anchored_hk_nearest_v2`，取消家長T0不得早於學生T0的限制。先獨立選學生，再優先依學生T1香港日期保留家長T1，從剩餘回應選最接近學生T0的一份。原標籤保留，不強行把T1候選用作T0：

| 家長建立日 | 分類及選取 |
| --- | --- |
| 早於學生T1（可早於學生T0） | T0候選，按實際建立時間與學生T0的絕對差距選最近一份，不選最早一份 |
| 學生T1當日或之後 | T1候選，選最新一份，不強行填補缺少的家長T0 |
| 尚未有學生T1 | 所有可靠日期的家長回應作T0候選，選最接近學生T0的一份，不設前後日數上限 |
| 未有可靠學生T0 | 另列未錨定回應，不推定正式家長T0／T1 |

T1資格按香港曆日，同日先填亦可；T0最近距離按實際建立時間計算。兩份回應與學生T0等距，或同輪並列時間無法唯一選取時，留待核實，不按檔案次序挑選。家長自身90日門檻取消，BD仍須同一成人。可有家長T1而沒有家長T0，此時可進F，不能進BD／EF。

先固定最近家長T0，再在同輪、同一成人確認通過後處理其前後30日內重填；重填不能把最近基線換成最早或最新一份。其他近距重填保留較新，不能跨T0／T1去重。輸出另列家長減學生的香港曆日差及實際時間差：負數為家長較早，正數為較遲。原始值、標籤、身份裁定及所有未選提交保留。

歷史 `student_anchored_hk_v1` 仍可重現2026-10-15的單向選取；沒有設定此政策的配置維持更早的各角色獨立90日選取。新發布不覆寫舊結果。

家長短期重填使用與 BD 一致的成人身份檢查；不同或未知成人不因日期接近而互相去重。BD以新選定的基線成人為錨，只從學生T1時段找同一成人，其T1可不同於家庭最新家長回應；BD不再保證家長自身測量間隔達90日。

目前研究政策允許以現有建立時間判斷日期資格，批次日期仍明確標記，不能稱為已核實實際填卷日期。日期缺失、並列或較早的新基線需要受控核實。

## 親子樣本

- AC：同一孩子的學生 T0／T1。
- BD：同一孩子、同一成人的家長 T0／T1。
- E：學生 T0＋所指同一孩子的家長 T0。
- F：學生 T1＋所指同一孩子的家長 T1。
- EF：四份回應全部指向同一孩子，可更換家長填卷人。

E／F先要求同一孩子，再按上述學生錨定日期分輪，沒有額外固定日數上限。EF不能只因成人ID相同就跨孩子連結；同一成人量表的跨期分析使用BD，須參考另列的家長實際測量間隔。

## 審核提示與批准

### 一般審核的派工範圍（2026-10-15）

候選搜尋、身份配對及審核派工是不同層次。歷史候選仍保留，但不能把所有 `pending` 比較當成人工工作量。一般審核包只選「基本孩子身份完整且一致、兩份均有可用聯絡、仍有聯絡或群組歧義」的比較；指定 case ID、獨立重審及重新指派亦須通過相同過濾。

- 完整孩子生日不同、有效孩子性別不同、問卷類別不符、提交已被排除：只作背景，不進一般身份審核。孩子生日／性別矛盾也不進品質抽查卡；疑似錯字由指定執行者用原有資料更正流程處理。
- 任一方沒有有效電話及電郵：列「無可用聯絡，不派審」，不建立補資料待辦。只缺電話但有有效電郵，仍屬可追查。
- 孩子生日／有效性別／學校缺失，或成人年份缺失／無效，但兩方均有聯絡：另列資料更正，不當作身份審核卡。
- 有效人工不配對及其連鎖限制、成人年份不同：轉指定執行者，不交助手猜測。成人比較仍先確認同一孩子。
- 年級、班號、正常升級、轉校、日期間隔、成人關係不同及本人聯絡不同，均不自行構成派審排除理由；已接受的電話差一位及任一精確聯絡規則保留。

一般派工預設 `purpose=review`，只處理待審比較。品質抽查另用 `purpose=validation`，可抽查沒有上述矛盾或缺失的已確認／已拒絕比較。既有成人年份逐宗例外保留；`purpose=adjudication` 只供指派 Jarvis 的明確裁定，不是助手的普通身份審核。沒有模式可繞過孩子生日／性別矛盾及無可用聯絡的排除。

派工分類即時計算，不改寫原始資料、歷史候選、人工決定或發布樣本；背景資料仍可出現在相關群組參考。舊包已填答案保留，毋須為新派工規則重新填寫。身份證據、群組或研究配對規則真正改變時，仍按既有版本檢查重新核實。

### 孩子身份按群組派審

一般孩子身份工作以 `GROUP_…` 為單位，一個相連候選群組只派一宗。已符合直接聯絡規則的兩份比較只作證據，不再逐對派卡。群組包含相關已確認身份成員，並檢查全組生日、性別、資格、聯絡及有效人工不配對限制；有矛盾或資料不足的整組交指定執行者，不讓乾淨的代表比較掩蓋其他成員。

2026-10-16 起，合併資料設定啟用 `matching_policy.allow_contact_bridge_components=true`，並以 `allow_contact_subgroups=true` 逐個聯絡連通子群確認。每個子群的所有成員須有完整一致的孩子生日、有效一致的孩子性別、學校及有效聯絡；子群內不得有身份矛盾、失效而重開的人工決定或有效人工不配對限制。每一條直接連結仍須符合既有同校精確聯絡、同校電話同一位置恰差一位，或轉校精確聯絡的規則。不要求每兩份問卷都有直接共同聯絡。較大候選群組尚有其他未連起子群，不再阻止證據充分的子群獨立通過；但不得切開既有人工／已確認身份群組，相關隱藏成員必須一併檢查。

自動確認使用 `child_contact_bridge_component`，保存完整成員、直接連結及間接比較證據，另輸出 `automatic_child_groups.xlsx`。子群證據另記原候選群組 ID、`scope=contact_subgroup` 及 `accepted_contact_subgroup_v1`；已有直接確認的身份不重複計作新增子群。不偽造人工 MATCH／LINK 或覆寫既有人工裁定。只關閉 `allow_contact_subgroups` 時保留舊有整組門檻；關閉 `allow_contact_bridge_components` 則保留逐對嚴格模式，供歷史版本重現。同一成人規則維持原樣，不能把家庭內不同成人沿聯絡連結合併。

「仍有未連起的子群」先列作「證據不足，待新資料（暫不合併）」，不因同生日、同性別、同校或電話近似就派卡。Jarvis 確認有原始紙本、收集紀錄或其他已核實來源可供查閱，登記位置及具體問題後，才按整組派一宗審核；已確認子群內的直接或間接連結毋須重審。來源改變、群組或相關身份證據改變時，登記失效而返回待新資料。登記來源不自動產生 MATCH、NONMATCH、LINK 或 UNLINK，也不改正式樣本。確認不同表示整組並非同一孩子，不表示每兩份都不同；必須由 Jarvis 指定完整分組，才可產生組內 LINK 及組間 UNLINK。單數問卷正常保留，身份確認後另按既有學生及家長規則選 T0／T1。

科學候選範圍與助手派工分開計算：待新資料的比較仍參與候選發現及聯絡連通分析，不會因移出審核清單而消失或改變目前群組。新問卷補上有效聯絡後，照常依原有身份規則重新判斷。成人沒有共同聯絡而又沒有可核實來源的待審比較同樣等待新資料；出生年份矛盾及其他更正／裁定限制保留。

同一成人比較仍以兩份家長問卷為單位，不把家庭內不同成人連成同一成人。背景生日／性別矛盾、無聯絡及資料待更正的比較不參與一般身份群組的候選連結。

年級／日期提示按香港時間及研究負責人確認的學年定義比較：9月1日至翌年8月31日為同一學年，跨過下一個9月1日才增加一個學年，並非以相隔365日判斷。跨一個學年正常升一級；小六轉中一按連續學段第6級至第7級比較，正常升一級，原始／整理年級仍分別保留6及1。小學、中學階段取自明確年級標示或已知學校分類；兼有兩個學段且只有數字時不猜測。

升幅過大、年級下降、跨學年不變、學段不明、缺失時間及批次日期均保留提示。正常升級是支持資料合理性的證據，並非身份確認的必要條件，也不取代已接受的聯絡規則。提示不會自行更正、拒配或排除；90日T1資格另行計算。

同事先提交審核答案，指定執行者預覽、批准及套用後，再重跑與發布。Dashboard 只讀已發布資料。已知 NONMATCH 尚被確認時禁止發布；程式測試不證明真實配對準確度。見[同事指南](REVIEW_CARDS_COLLEAGUES.md)及[執行者指南](REVIEW_CARDS_OPERATIONS.md)。
