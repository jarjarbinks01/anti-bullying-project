# 現行身份、跨期及親子配對規則

本文件只說明程式規則，不包含真實個案、數量或審核答案。

## 孩子身份

提交、孩子及成人填卷人分開識別。電話不能單獨代表孩子；家長回應先確認所指孩子。

自動確認要求完整孩子生日、有效性別一致、已映射學校、候選唯一，而且整個群組沒有身份矛盾。已接受三類聯絡規則：同校及精確電話／電郵；同校及有效電話恰好在同一位置差一位數字；不同校但精確聯絡一致。

電話近似兼轉校、互換兩位、位數不同、生日／性別缺失或矛盾，以及無法區分的多候選人，不自行合併。班號只在可比情境支持判斷；跨年不要求班號固定。缺失身高／體重不是身份證據。

逐對相符仍須檢查整組一致性，避免共享聯絡形成矛盾連鎖。提交總數的奇偶不作身份或去重條件。

## 同一成人與 BD

BD 要求同一孩子及同一成人。自動成人確認須有有效、一致的出生年份及與孩子關係；兩份都填「其他」時，關係文字亦須一致。

本人精確聯絡一致優先。啟用 `allow_exact_general_contact_when_personal_missing` 後，至少一份缺少可用本人聯絡時，可接受其他聯絡欄位的精確電話或電郵一致。兩份本人聯絡均有填但不同，不套用後備規則。成人電話差一位不能只靠這個後備規則通過。

成人年份、關係缺失或矛盾仍須人工核實。有效人工決定優先；已接受出生年份錯字而正確年份未知時，保留原值及 `adult_birth_year_status=unconfirmed`。例外只適用於已核實的兩份提交，不能延伸至第三人的矛盾證據。互相矛盾的人工決定須重新裁定。

## 輪次及短期重填

學生與家長按同一孩子分開選輪次。T0 是最早合資格原始回應，短期重填不取代基線。原標 T1 的首次回應可推定 T0，保留原標籤及理由。

T1 選最新且距 T0 至少 90 × 24 小時的合資格回應。後續的 30 日內重填保留較新回應；30–89 日保留為未達門檻 follow-up。所有提交及排除理由仍保留，排除不是刪除原始資料。

家長短期重填使用與 BD 一致的成人身份檢查；不同或未知成人不因日期接近而互相去重。BD 以基線成人為錨，其合資格 T1 可不同於家庭最新家長回應。

目前研究政策允許以現有建立時間判斷日期資格，批次日期仍明確標記，不能稱為已核實實際填卷日期。日期缺失、並列或較早的新基線需要受控核實。

## 親子樣本

- AC：同一孩子的學生 T0／T1。
- BD：同一孩子、同一成人的家長 T0／T1。
- E：學生 T0＋所指同一孩子的家長 T0。
- F：學生 T1＋所指同一孩子的家長 T1。
- EF：四份回應全部指向同一孩子，可更換家長填卷人。

E／F 不限制學生與家長填卷日期差。EF 不能只因成人 ID 相同就跨孩子連結；同一成人量表的跨期分析使用 BD。

## 審核提示與批准

年級／日期提示按香港時間、9月學年分界及已知學段比較，涵蓋跳級、下降、跨學年不變、學段不明、缺失時間及批次日期。學年分界是初步核實假設；提示不會自行更正、拒配或排除。

同事先提交審核答案，指定執行者預覽、批准及套用後，再重跑與發布。Dashboard 只讀已發布資料。已知 NONMATCH 尚被確認時禁止發布；程式測試不證明真實配對準確度。見[同事指南](REVIEW_CARDS_COLLEAGUES.md)及[執行者指南](REVIEW_CARDS_OPERATIONS.md)。
