# 同事填寫指南：逐宗身份審核

你會收到一份已填好審核者姓名的 `.xlsx`，通常有 20 宗。毋須安裝 Python、巨集或外掛。不要改檔案內的審核者、識別碼或證據，也不要移动、刪除或排序卡片。

1. 開啟「審核目錄」，按「開啟個案」。
2. 閱讀該宗問題。孩子／親子案例問的是「是否指向同一孩子」；成人案例問的是「是否由同一成人填寫」。家長回應指向同一孩子，並不代表填卷人相同。
3. 比較左右證據。親子案例學生固定在左；其他案例按目前觀察日期排列。兩邊都沒有資料會寫「兩方缺失」，不能當作相同的證據。身高、體重缺失也不能支持身份判斷。
4. 只填三個黃色格：「審核結論」、「主要證據來源」、「補充理由」。理由必須說明判斷及證據位置，例如「核對原始紙本，學生第 12 頁及家長第 16 頁均為同一孩子，生日、班號及家長電話一致」。這是寫法示例，不是任何真實個案的證據。
5. 如有需要，按卡片底部連結查「群組參考」。這裡有其他相關提交、來源位置、程式原判斷及規則；沒有其他同事的審核答案。
6. 按「下一宗」，最後儲存並交回同一格式的 `.xlsx`。沒有開始的個案可完全留白；已開始則三項都要填完。長理由可選中黃色格，在 Excel 公式列閱讀完整文字。

孩子身份案例可比較跨期回應，也可比較同一輪次的多次提交。這一步只核實身份；是否屬 T0／T1、是否短期重填及是否達 90 日，仍由既有規則及工具處理。

## 如何選結論

| 選項 | 何時使用 | 批准後的效果 |
|---|---|---|
| 確認相同 | 已有足夠證據確認同一孩子／成人 | 保存核實結果，需要時補上身份連結 |
| 確認不同 | 已有足夠證據確認不同孩子／成人 | 保存核實結果，阻止相關身份連結 |
| 資料不足 | 目前資料未能支持確定判斷 | 保留目前配對，記錄待複核工作 |

電話相同本身不能確認孩子，兄弟姊妹或雙胞胎需要其他可區分資料。同校、生日、性別相同亦不一定足夠。親子填卷日期不同，不是拒配條件。成人身份須另外核對本人資料；孩子的共同聯絡電話不能單獨證明同一成人。

若發現學校、生日、日期或答案輸入有錯，請在理由指出欄位、正確值及原始證據位置，交 Jarvis 使用既有工具修正，重新取得證據後再審核。不要直接改卡片的證據。

「已填寫」只代表三項齊備，未代表已驗證或批准。正式結果須經收回驗證、Jarvis 批准、套用及發布後才出現在 Dashboard。

工作包只含你的個案及必要參考，仍有參加者身份資料。交回既有研究團隊的受控儲存位置。
