# 階段說明

每段按同一格式說明。原有 0.2 與 1.2 不納入本版運行；0.1 問卷樣本供欄位及量表核對。

目前從2.1.2的四份已合併Excel開始。1.1／1.3／2.1.1是原流程提供的上游結果，不在本版重複執行；以下同時說明原階段用途及新版本接入點。

## 1.1 登記及匯入原始資料

- **目的：** 保留所有原始提交與來源版本，避免重複下載增加提交。
- **輸入：** 目前接入四份2.1.2合併Excel、完整ready清單及固定欄位；1.1不另外匯入。
- **輸出：** submissions、submission_versions、run_records；來源副本。
- **一行：** 一份原始提交；同一提交可以有多個內容版本。
- **規則：** 目前合併檔缺少永久提交ID：所有來源首次登記原始行及完整內容，重排用內容對應；原內容修改／刪除而身份無法確認時停止。原始来源的Qualtrics／舊系統ID機制保留但本版不直接讀入。
- **執行：** `study2 manifest`、`study2 validate --step 1.1 --manifest …`、`study2 run --manifest …`。
- **人工工作：** 核實來源 namespace，登記新來源或欄位；不可猜測碰撞身份。
- **常見錯誤：** 來源缺失、未知欄位、不是完整快照、已登記內容無法對應的修改／刪除。
- **驗收：** 相同輸入或重排不增加提交；來源消失／鍵變更不得靜默發布。

## 1.3 紙本標準化

- **目的：** 對齊一般紙本、Social Work Dream 和三所學校資料。
- **輸入：** 原流程的紙本／學校來源；目前新程式只接收其在2.1.2的已標準化結果。
- **輸出：** 統一答案欄位、原始行登記、批次日期與日期可信度。
- **一行：** 一份紙本登錄提交，不代表已核實的獨立孩子。
- **規則：** 原程式已把FQOL0–4轉為1–5；新版本不再加1。按2026-10-06決定，使用目前建立時間判90日，保留批次日期來源，不證明實際日期。
- **執行：** `study2 validate --step 1.3 --manifest …`；正式使用完整 run。
- **人工工作：** 核實日期或修正標準化答案；無法對應的原行修改須停止。
- **常見錯誤：** 數字電話多出小數位、多個電話被拼接、日期只有批次可信度。
- **驗收：** 原值可追查；重排不換 ID；批次日期按已接受政策判資格，但日期來源與實際年齡缺失須保留。

## 2.1.1 網上資料標準化

- **目的：** 對齊舊系統不同問卷版本及現行 Qualtrics。
- **輸入：** 原流程的網上匯出；目前只接收其在2.1.2的已標準化結果，不重新讀四份CSV。
- **輸出：** 統一答案、來源原輪次、完成狀態及原始觀察時間。
- **一行：** 一份網上提交；未完成或未知問卷也保存。
- **規則：** 原網上轉換使用既有欄位映射及完成資格；目前合併檔已是標準化答案，直接接入，不重新转碼或推定不存在的ResponseId。
- **執行：** `study2 validate --step 2.1.1 --manifest …`。
- **人工工作：** 核實新選項或問卷版本；不可默認未知選項為零。
- **常見錯誤：** ResponseId 缺失、未知選項、建立時間缺失或鍵碰撞。
- **驗收：** 完成與未完成數可核對；相同 ResponseId 的更新保存新版本。

## 2.1.2 合併來源

- **目的：** 把紙本及網上提交置於同一資料模型。
- **輸入：** A_T0-student_merged.xlsx、B_T0-parent_merged.xlsx、C_T1-student_merged.xlsx、D_T1-parent_merged.xlsx。
- **輸出：** 同批次的完整記錄集合及來源位置。
- **一行：** 一份提交；此階段尚未去重或推定孩子身份。
- **規則：** 不以答案相似或電話相同直接刪除；整行完全相同、原始來源及標準化答案也相同的額外副本列為exact_input_repeat，保留全部原始行及代表ID。
- **執行：** `study2 validate --step 2.1.2 --manifest …`。
- **人工工作：** 調查來源缺失或意外縮減。
- **常見錯誤：** 增量匯出被誤當完整快照。
- **驗收：** 每個來源貢獻及總提交數核對；全部排除仍留在原始資料庫。

## 2.1.3 校名、年級及答案檢查

- **目的：** 使用共同校名字典，整理年級及有效題目編碼。
- **輸入：** 合併提交、本機版本化字典。
- **輸出：** 校名／學校特徵、未知校名清單、資格與答案問題標記。
- **一行：** 同一份提交，新增清理值及狀態。
- **規則：** MAP 用正式校名；DELETE 排除而不刪原始提交；不猜測不清楚年級。缺失或非法題目保持缺失。
- **執行：** 完整 run 後 `study2 validate --step 2.1.3`。
- **人工工作：** schools 審核表填 MAP／DELETE、原因及審核者。
- **常見錯誤：** 字典 key 衝突、校名未知、題目超出編碼、答案過少。
- **驗收：** 字典改動可追查；主流學校與其他／未知學校另列。

## 2.1.4 確認孩子身份及親子指向

- **目的：** 確認提交是否屬於同一孩子；家長回應以所指孩子分組。
- **輸入：** 合資格提交、可用的人工身份決定。
- **輸出：** 穩定 child_id、確認／待審／拒絕候選及決定事件。
- **一行：** 身份成員表是一份提交指向一個暫定或確認的孩子群組；候選表是一對提交或一個待審提交。
- **規則：** 完整生日、性別相同，另須同校精確聯絡、同校電話恰差一位、或轉校但精確聯絡。候選唯一且整組一致，電話近似兼轉校／多候選／矛盾連鎖待審。另判成人，不把孩子連結當作成人連結。
- **執行：** 完整 run；`study2 validate --step 2.1.4`；review-export／review-import。
- **人工工作：** 核實未達自動門檻的電話錯誤、共享電話、雙胞胎、多候選人、成人證據不足及漏配。
- **常見錯誤：** 身份證據不足、舊人工決定遇到新矛盾、互相矛盾的 LINK／UNLINK。
- **驗收：** 已知 NONMATCH 不得自動確認；來源版本改變後不繞過重新審核。

## 2.1.5 T0、短期重填及 T1

- **目的：** 在確認孩子身份後，按每個孩子／填卷類別選輪次。
- **輸入：** 身份群組、目前建立時間或人工核實時間、資格狀態；批次建立時間已获接受。
- **輸出：** T0／T1 選擇、重填指向、未滿 90 日及其他 follow-up 狀態。
- **一行：** 同一份提交的分析選擇，不是刪除紀錄。
- **規則：** 先固定最早合資格 T0。0／29／58／87／120 日例子中，0 日是 T0，120 日是 T1；29 日短期重填、58／87 日未達門檻。90 日以後的近距重填保留較新合資格回應；最新合資格 follow-up 成為 T1。
- **執行：** 完整 run；`study2 validate --step 2.1.5`。
- **人工工作：** 處理缺失或並列日期。紙本目前建立時間已獲接受用於90日，但仍保留批次標記。
- **常見錯誤：** 連續重填把基線推後、日期缺失、來源日期異常。
- **驗收：** 29／30／89／90 日及三份以上案例符合指定結果。

## 2.1.6 持續人工修正

- **目的：** 沿用核實決定、救回誤排除、拆分及補上身份連結。
- **輸入：** 最新版本審核包、來源版本、審核者及理由。
- **輸出：** 追加式 decisions、supersedes 關係、套用／重新待審事件；新完整運行。
- **一行：** 一項受控人工決定。
- **規則：** 有效決定優先；失效ID／版本衝突整包拒絕；身份證據變更重新待審；LINK_ADULT獨立處理同一成人，不能改孩子身份。本版不按舊重編號自動遷移。
- **執行：** review-export、review-import，然後建立清單重跑。
- **人工工作：** 詳見操作指南的 action 表；核實集標籤與操作分開。
- **常見錯誤：** 編輯識別欄、沒有理由、矛盾三角連結、對舊版本修改。
- **驗收：** 無效包不部分寫入；重跑保留有效決定；孩子及成人決定分開；現有舊修正须由研究同事對應新穩定ID核實。

## 3.1.1 A–D 及 AC／BD

- **目的：** 輸出每輪學生／家長回應和跨期樣本。
- **輸入：** 最終輪次選擇。
- **輸出：** A=T0學生、B=T0家長回應、C=T1學生、D=T1家長回應；AC／BD 寬表。
- **一行：** A–D 是一份選定回應；AC是同一孩子兩輪學生回應；BD是同一孩子、同一成人的兩輪家長回應。
- **規則：** 每個孩子／類別／家庭輪次最多一份。BD以基線家長為錨，選該成人最新合資格≥90日回應；可與D／F使用的家長回應不同。原標籤、理由、成人證據及ID另列。
- **執行：** run 產生版本化 Excel；validate --step 3.1.1。
- **人工工作：** 檢查數量變動和待審個案，不在發布 Excel 直接改數據。
- **常見錯誤：** 混用不同 RUN 檔案、把 BD 稱作已確認同一位家長。
- **驗收：** AC=C；BD≤同一孩子家長回應跨期數，BD不要求D全部為同一成人。dashboard、資料庫和Excel數量一致，BD專用tall視圖為每組两行。

## 3.1.2 每輪親子樣本 E／F

- **目的：** 連結同一孩子的學生與家長回應。
- **輸入：** 每個孩子的選定 A–D。
- **輸出：** E=T0親子、F=T1親子，另列 student_only／parent_only。
- **一行：** 同一孩子在指定輪次的一份學生及一份家長回應。
- **規則：** 不限制兩份回應日期差；須指向同一 child_id。日期差及可信度保留，不聲稱同時觀察。
- **執行：** 完整 run；validate --step 3.1.2。
- **人工工作：** 身份歧義須在 review 包解决，不選第一個家長。
- **常見錯誤：** 共享電話錯配兄弟姊妹；把確認身份誤當同時填卷。
- **驗收：** 每輪每孩子只有一個親子組合；未解決連結不形成配對。

## 3.1.3 修正親子及 EF

- **目的：** 輸出已套用修正的 E／F，連結跨期親子樣本。
- **輸入：** E／F 及有效人工決定。
- **輸出：** E／F final、EF final、填卷人資料變更標記及描述統計資料。
- **一行：** EF 是同一孩子的兩輪學生與家長回應，共四份選定提交。
- **規則：** 以孩子連結；不能只因家長 ID 相同合併。成人出生年份、關係及本人聯絡另判一致性；變更／未知不阻止已確認同孩子的EF，但不能進BD。
- **執行：** 完整 run；validate --step 3.1.3。
- **人工工作：** 核實照顧者變更；不能推定前後都是同一填卷人。
- **常見錯誤：** 跨孩子 EF、誤把家長年齡欄當關係欄。
- **驗收：** EF 的四份回應都屬同一孩子；E／F／EF 與分析 cohort 標記一致。

## 發布與描述統計

- **目的：** 讓 Excel 和 dashboard 引用同一已檢查版本。
- **輸入：** 完整運行、核實標籤、計分及檔案／備份檢查。
- **輸出：** 不可變 RUN 資料夾、目前版本指標、還原備份、品質及描述統計頁。
- **一行：** analysis.parquet是家庭視圖的一份選定回應；parent_longitudinal.parquet是BD的一份選定成人回應；統計表是一個篩選樣本的一項指標。
- **規則：** 共用計分層只算一次；完整題目才出正式分數；每項顯示有效 N、分母及缺失；主流學校分析另列其他與未知。
- **執行：** publish／rollback／dashboard／watch。
- **人工工作：** 研究團隊核實案例集與版本可比性；報告明確引用 RUN。
- **常見錯誤：** 更新失敗、資料過期／匯出時間未知、缺題當作零、拿候選數當人數。
- **驗收：** 失敗保留舊版；指標可恢復；備份可還原；核實覆蓋與未能判定比例可查。
